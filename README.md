# AngularApp

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.1.2.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

## Backend configuration (Spring Integration)

The Angular app reads backend URL from `public/runtime-config.js`.

- Default value: `http://localhost:8080/api`
- To point to `pim_spring_integration`, update:

```js
window.__PIM_API_BASE_URL__ = 'http://localhost:8080/api';
```

If your Spring Integration backend runs on another host/port, change this value accordingly, then restart `ng serve`.
